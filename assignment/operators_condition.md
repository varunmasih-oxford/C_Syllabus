### **1. Basic Arithmetic Operator**

Write a C program that takes two integers from the user and prints:

* Their sum
* Their difference
* Their product
* Their division

---

### **2. Modulus Operator**

Write a program to input a number and print whether it is **even or odd** using the modulus (`%`) operator.

---

### **3. Relational Operator**

Write a program that takes two numbers and prints which one is **greater**, or if they are **equal**.

---

### **4. Check Positive, Negative or Zero**

Write a program that inputs a number and checks whether it is:

* Positive
* Negative
* Zero

---

### **5. Voting Eligibility**

Write a program that asks the user’s age and checks if the person is **eligible to vote** (age ≥ 18).

---

### **6. Simple Calculator Using Operators**

Write a program that takes two numbers and an operator (`+`, `-`, `*`, `/`) from the user and performs the calculation using **if-else conditions**.

---

### **7. Logical AND Operator**

Write a program to check if a number lies **between 10 and 50** (inclusive) using the logical AND (`&&`) operator.

---

### **8. Logical OR Operator**

Write a program to check if a character entered by the user is a **vowel** (a, e, i, o, u) using logical OR (`||`).

---

### **9. Largest of Three Numbers**

Write a program to input three numbers and print the **largest** using relational and logical operators.

---

### **10. Pass or Fail Condition**

Write a program that asks for marks (0–100).

* If marks ≥ 40 → Print **Pass**
* Otherwise → Print **Fail**
