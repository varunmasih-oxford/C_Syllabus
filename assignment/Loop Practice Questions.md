# C Programming – Loop Practice Questions

## Topic: for loop, while loop, do-while loop, break, continue

### Practice Questions

1. Write a `for` loop to print numbers from **1 to 20**.

2. Write a `while` loop to print **even numbers from 2 to 50**.

3. Write a `do-while` loop that prints **"Hello World" 5 times**.

4. Write a program to print the **sum of numbers from 1 to 10** using a loop.

5. Write a `for` loop that stops printing when the number reaches **7** using the `break` statement.

6. Write a program that **skips the number 5** while printing numbers from **1 to 10** using the `continue` statement.

7. Write a program to print numbers from **10 to 1** using a loop.

8. Write a program to print **only odd numbers** between **1 and 20**.

9. Write a loop that prints the **multiplication table of 5**.

10. Write a program to count how many numbers between **1 and 100** are divisible by **3**.
