## 8: Strings

### What is a String?

* A string is an **array of characters**
* Ends with **null character `\\0`**

```c
char name[] = "C Programming";
```

---

### String Input/Output

```c
char name[20];
scanf("%s", name);
printf("%s", name);
```

---

### Common String Functions (`string.h`)

| Function   | Purpose     |
| ---------- | ----------- |
| `strlen()` | Length      |
| `strcpy()` | Copy        |
| `strcmp()` | Compare     |
| `strcat()` | Concatenate |
