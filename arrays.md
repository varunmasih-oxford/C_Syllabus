## 7: Arrays

### What is an Array?

* Collection of **same type of data**
* Stored in **contiguous memory**

---

### One-Dimensional Array

```c
int arr[5] = {10, 20, 30, 40, 50};
```

Accessing elements:

```c
printf("%d", arr[2]);  // 30
```

---

### Two-Dimensional Array

```c
int matrix[2][2] = {{1, 2}, {3, 4}};
```
